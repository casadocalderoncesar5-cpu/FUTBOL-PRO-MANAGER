Endpoints Disponibles en la API REST

Método Ruta Endpoint Descripción Prueba
GET /api/clubes Retorna todos los clubes con sus referencias resueltas en formato JSON Abrir JSON
POST /api/clubes Guarda un nuevo club en MongoDB Atlas enviando un payload JSON Probar Form
GET /api/competiciones Retorna todos los torneos mundiales oficiales en formato JSON Ver Torneos
GET /api/asociaciones Retorna todas las federaciones deportivas mundiales en formato JSON Ver Federaciones
GET /api/arbitros Retorna los árbitros internacionales registrados en formato JSON Ver Árbitros
DELETE /api/clubes/{id} Elimina el documento del club de la colección clubes en MongoDB Atlas Ir a Tabla
